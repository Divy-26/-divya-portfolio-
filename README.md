# Divya Gupta - Portfolio

Modern editorial portfolio showcasing UX/UI and digital campaign design work.

## Features

- **Premium Typography** - Oversized headlines with clean editorial hierarchy
- **Campaign Projects** - Social media, CRM, OOH, and presentation work
- **3 Focused Projects**:
  - Adidas Street Mode (Campaign, Social, CRM, Branding)
  - Smart Home Experience (UX/UI, Product Design)
  - Nykaa Social Campaign (Social, Branding, Digital)

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)
- Vite

## Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

## Deployment

## Design Approach

- Bold typography with `tracking-tighter` and oversized headlines
- Minimal text, visual-first presentation
- Tight color palette: #0D0D0D (black), #F5F5F3 (off-white), #FF6B3D (orange accent)
- Premium mockups with realistic proportions
- Editorial fashion-inspired layouts

Built for TMW/Accenture Song creative agency application.
